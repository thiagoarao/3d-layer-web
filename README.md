# 3D LAYER — CRM da Loja 3D (versão web)

**Ideias que ganham formas.**

Versão web do aplicativo CRM 3D STORE: clientes, estoque, vendas, pedidos e
catálogo 3D — acessível de qualquer computador ou iPad.

## Como atualizar

1. Na pasta do aplicativo (desktop), rode: `npm run build:web`
2. Substitua o conteúdo desta pasta pelo gerado em `crm-3d-store/dist-web`
3. Faça o push para este repositório — o GitHub Pages republica sozinho.
